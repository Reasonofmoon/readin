# 리드인 신중점 샘플 웹사이트 계획

## 브리프
- 대상: 독서논술학원 "리드인 신중점", 좌우명 "밑 빠진 독에 물 붓기"
- 독자: 초등~중등 학부모 (모바일 비중 높음)
- 페이지의 일: 좌우명을 한 번에 납득시키고 상담 신청으로 연결

## 컨셉
콩나물시루 비유. 물(글자)은 독 밑으로 다 새지만, 그 물줄기가 페이지 끝까지 흘러 콩나물을 키운다.

## 토큰
- 색: 물 #2347E2, 깊은 물 #1733B0, 종이 #F4F7FC, 먹 #131A33, 옹기 #6B4330, 콩 #FFD447, 새싹 #35B37E, 빨간 펜 #E5342B
- 서체: Bagel Fat One(제목, 장난기) + Gowun Batang(본문, 책 느낌) + Nanum Pen Script(첨삭 메모 전용)
- 정렬: 좌측 정렬. 본문 왼쪽 여백에 물줄기가 흐른다.

## 레이아웃
```
[nav]
[hero: 제목+사전쪽지+버튼 | 깨진 독(canvas+svg)]   <- 유일한 상시 모션
~~~~ 물결 ~~~~
| 철학 (본문 | 새는 것/남는 것 장부)
| 수업 90분 (순서 목록 | 원고지 첨삭)
| 반 안내 (행 목록)
| 이달의 책 (책등 책장, 선택형)
| 묻고 답하기 (details)
~~~~ 물결 ~~~~
[closing: 콩나물 자람 + 상담 신청 폼]
```
`|` = 스크롤에 따라 내려오는 물줄기.

## 기본값 회피 점검
- 크림+테라코타, 검정+형광, 신문형, 카드 키트 모두 사용 안 함
- 번호는 실제 순서(수업 흐름)에만 사용
- 섹션마다 fade-up 없음. 모션은 히어로 물 붓기, 스크롤 물줄기, 마지막 콩나물뿐
